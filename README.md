# 🟡 Pac-Man Clone (Java)

A simple **Pac-Man** clone built in **Java** using [JavaFX/Swing ].  
This project was created as a personal game development challenge and learning experience.

---

## 🎮 Features

- Classic Pac-Man-style movement
- Dot collection logic
- Game-over detection
- Simple object-based architecture in Java

---

## 🚀 Getting Started

### ✅ Prerequisites
- Java JDK 8 or higher installed
- A terminal or IDE like IntelliJ or Eclipse

### 🧪 Running the Game

#### Option 1: Using Terminal
```bash
javac *.java
java App
